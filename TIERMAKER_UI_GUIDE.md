Click tier name \"S Tier\"\n   ↓\n2. Input field appears with focus: [S Tier]\n   ↓\n3. User types \"GOATED\"\n   ↓\n4. User presses Enter\n   ↓\n5. Header updates: [🔴] GOATED (3) [↑] [↓] [✏️] [🗑️]\n   ✅ Saved to database\n`\n\n#### Flow 2: Change Color\n\n`\n1. Click color square [🔴]\n   ↓\n2. Color picker popup appears\n   ↓\n3. User clicks blue preset or uses custom picker\n   ↓\n4. Color changes immediately: [🔵]\n   ✅ Saved to database\n   ↓\n5. Popup closes\n`\n\n#### Flow 3: Move Tier Down\n\n`\nBefore:\n  S Tier [↑] [↓]\n  A Tier [↑] [↓]\n  B Tier [↑] [↓]\n\n1. Click [↓] on S Tier\n   ↓\n2. S Tier swaps with A Tier\n   ↓\nAfter:\n  A Tier [↑] [↓]\n  S Tier [↑] [↓]\n  B Tier [↑] [↓]\n  ✅ Saved to database\n`\n\n#### Flow 4: Move Item Within Tier\n\n`\nOption A: Drag\n  1. Drag card left/right\n  2. Drop at new position\n  3. Smooth animation\n  ✅ Saved to database\n\nOption B: Click Buttons\n  1. Hover over card\n  2. Move buttons appear: [←] [→]\n  3. Click [→] to move right\n  4. Smooth animation\n  ✅ Saved to database\n`\n\n#### Flow 5: Drop Item at Position\n\n`\nOLD (Before):\n  Tier contains: Item A, Item B\n  1. Drag Item C to tier\n  2. Drop anywhere\n  3. Item C goes to END (append-only)\n  Result: Item A, Item B, Item C\n\nNEW (After):\n  Tier contains: Item A, Item B\n  1. Drag Item C to tier\n  2. Drop ON Item B (not just tier)\n  3. Item C inserts BEFORE Item B\n  Result: Item A, Item C, Item B ✅\n  \n  OR\n  \n  1. Drag Item C to tier\n  2. Drop in empty space\n  3. Item C goes to END\n  Result: Item A, Item B, Item C ✅\n`\n\n### Keyboard Shortcuts\n\n`\nWhile renaming tier:\n  Enter  → Save & close\n  Escape → Cancel (no save)\n  Tab    → Next button\n\nWith focus on button:\n  Space  → Activate\n  Enter  → Activate\n  Tab    → Next element\n`\n\n### Mobile Touch Interactions\n\n`\nTier Editing:\n  • Tap tier name → Inline edit appears\n  • Tap color → Color picker appears\n  • Tap ↑/↓ → Tier moves\n  • Tap 🗑️ → Confirmation dialog\n\nItem Reordering:\n  • Swipe left/right → Move item\n  • Long press → Drag mode\n  • Tap move buttons → Move one position\n`\n\n### Responsive Layouts\n\n`\nDesktop (1024px+):\n  ┌─────────────────────────────────┐\n  │ [🎨] Tier Name (count)  [↑][↓][✏️][🗑️] │\n  │ [Card] [Card] [Card] [Card]     │\n  └─────────────────────────────────┘\n\nTablet (768px-1023px):\n  ┌──────────────────────┐\n  │ [🎨] Tier Name (cnt) │\n  │ [↑][↓][✏️][🗑️]      │\n  │ [Card] [Card]        │\n  │ [Card] [Card]        │\n  └──────────────────────┘\n\nMobile (< 768px):\n  ┌─────────────────┐\n  │ [🎨] Tier (cnt) │\n  │ [↑][↓][✏️][🗑️] │\n  │ [Card]          │\n  │ [Card]          │\n  │ [Card]          │\n  └─────────────────┘\n`\n\n### Error States & Confirmations\n\n`\nDelete Tier:\n  ┌─────────────────────────────────┐\n  │ Delete tier \"S\"?
