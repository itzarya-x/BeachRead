# Ani Vault

Ani Vault is a React + TypeScript app for viewing and working with AniList archive data.

## Project info

- Framework: Vite + React + TypeScript
- UI: shadcn-ui + Tailwind CSS

## Development

Requirements:

- Node.js
- npm

Run locally:

```sh
git clone https://github.com/itzarya-x/Ani-Vault.git
cd Ani-Vault
npm install
npm run dev
```

Build for production:

```sh
npm run build
```

Preview production build:

```sh
npm run preview
```

## Testing

```sh
npm test
```
