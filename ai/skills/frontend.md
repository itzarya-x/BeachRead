# Yura Frontend Skill System

Yura is a personal media discovery & analytics product.

PRINCIPLE:
Content first. UI second.

Users should see posters immediately.
Avoid large hero or marketing sections.

Homepage uses horizontal discovery rows.
Cards dominate layout.

Cards must contain:
- cover image
- title
- progress
- tier color if exists

Hover reveals quick actions.

Never center layouts.
Never create SaaS dashboards.
Never prioritize whitespace over density.

Use shadcn UI components for all primitives.

Animations:
subtle, fast, modern.

Everything must scale to thousands of items.
